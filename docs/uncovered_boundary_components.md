# 技能卡片：3D 网格未覆盖开放边界组件的提取与可视化

**技能领域**：3D 几何处理、网格诊断、计算几何

**核心指令**：`meshinspect.py --hole-diagnosis` 以及 `--visualize-boundary-component --boundary-type uncovered`

**应用场景**：3D 模型缺陷检测、3D 打印前处理、拓扑撕裂与复杂网格损坏分析。

## 1. 核心概念定义

在 3D 网格拓扑中，任何水密（Watertight）实体模型的所有边都应被两个面共享。**开放边（Open Edge / Boundary Edge）\**是指仅被一个面包含的边，它的出现意味着模型表面存在破损。所有的开放边会相互连接形成\**组件（Components）**。

在诊断系统中，这些缺陷组件被分为两类：

- **健康孔洞（Healthy Holes / Repairable Holes）**：指拓扑上完全闭合、几何形态相对简单且**算法可以直接安全修复**的网格缺失区域。
  - *注：这绝不是指模型主动设计的物理孔洞（设计的实体孔是有厚度且水密的，不含开放边）。“健康孔洞”通常指因扫描死角或格式转换丢失的少量三角面片，这类边界环往往周长较小且近似共面，可以通过常规的三角剖分（Triangulation）直接填补。*
- **未覆盖的开放边界（Uncovered Boundary）**：指除可修复孔洞之外的复杂、严重网格缺陷。通常代表**无法通过常规补洞算法直接闭合**的区域，例如：未闭合的线段（裂缝 Cracks）、极度扭曲且自交的边界环、大面积结构性丢失产生的游离悬空边等。

## 2. 提取方法 (对应 `--hole-diagnosis`)

`--hole-diagnosis` 指令触发了从底层拓扑分析到高级语义分类的完整提取流水线：

### 步骤 2.1：拓扑邻接关系构建与开放边定位

1. 遍历网格的所有面（Faces），提取所有的半边（Half-edges）。
2. 统计每条无向边的邻接面数量（Degree）。
3. 筛选出所有 `Degree == 1` 的边，标记为**开放边候选集**。

### 步骤 2.2：连通分量聚类（Component Extraction）

1. **构建无向图**：将开放边候选集作为图的边，开放边的端点作为图的节点。
2. **图遍历（DFS/BFS）**：从任意一个未访问的开放边节点出发，沿着相连的开放边进行深度优先或广度优先搜索。
3. **划分组件**：每次遍历闭环或到达尽头，即将经过的边归为一个**边界组件（Boundary Component）**。重复此过程直到所有开放边均被分配。

### 步骤 2.3：启发式分类与诊断（Hole vs. Uncovered）

系统对提取出的每一个“边界组件”计算几何与拓扑特征，以评估其“可修复性”：

- **拓扑闭合性检查**：如果是未闭合的链条（折线），说明是单纯的裂缝，直接判定为 `uncovered`。
- **几何复杂度计算**：对于闭合的边界环，计算其周长、面积，并通过主成分分析（PCA）评估边界顶点的**共面性（Planarity）**。
- **分类输出**：
  - 如果组件完全闭合，且满足一定的修复安全阈值（如面积较小、边界顶点近似共面），系统认为其可以通过网格平坦化或最小面积三角剖分进行修复，标记为 `hole`（可修复孔洞）。
  - 反之，如果闭合环极度扭曲、尺寸过大（超出自动修复的安全假设），或伴随复杂的非流形结构，则标记为 `uncovered`（未覆盖缺陷，通常需要复杂的拓扑重建或人工介入）。

## 3. 可视化方法 (对应 `--visualize-boundary-component --boundary-type uncovered`)

此指令组合负责将后台计算出的抽象拓扑缺陷映射到 3D 渲染上下文中，便于用户直观观察。

### 步骤 3.1：数据过滤与按需加载

1. 解析 `--boundary-type uncovered` 参数。
2. 在经过 `--hole-diagnosis` 产生的诊断结果集中，过滤掉标记为 `hole`（系统认为可静默修复）的组件，**仅保留**类型为 `uncovered` 的严重缺陷数据。

### 步骤 3.2：视觉属性映射 (Visual Mapping)

为了将缺陷与正常网格区分开，渲染引擎采取以下材质和着色策略：

- **基础网格弱化**：将原始 3D 网格模型设置为半透明（如 Alpha=0.3）或低对比度颜色（如浅灰色/线框模式），以减少视觉干扰。
- **高亮渲染**：
  - **线条加粗**：将 `uncovered` 组件的边渲染为粗线（Line Width = 3~5）。
  - **警示色**：使用高饱和度的警示色（如纯红色、亮品红色）对其进行着色。
  - **端点标记（可选）**：如果该组件是未闭合的裂缝，在裂缝的两个游离端点处渲染显眼的球体标记（Markers），提示断点位置。

### 步骤 3.3：相机交互与渲染

- 在 3D 视口中渲染上述元素。
- 如果缺陷较小，系统可能会自动计算 `uncovered` 组件的包围盒（Bounding Box），并调整相机的焦点和缩放比例，使其自动居中在视口中。

## 4. 命令行执行示例

```
# 完整诊断并只可视化那些“无法简单修复”的严重缺陷边界
python src/toys3d/meshinspect.py input_model.stl \
    --hole-diagnosis \
    --visualize-boundary-component \
    --boundary-type uncovered
```
